# Groove Prompt Builder

Groove Prompt Builder is a local, rule-based music composition and prompt design tool for Minimal Tech House, Deep Tech House, Dub Techno, and hypnotic club music.

The project goal is to turn track identity, structure, instrument choices, arrangement density, and production tags into clear prompts for tools such as Suno, Lyria, MusicFX, and similar AI music systems.

## Current Direction

- No external AI/API integration for the first implementation.
- Local data model based on the existing Minimal Tech House / Deep Techno Prompt Library.
- Studio-focused UI inspired by compact DAW/plugin workflows such as Ableton Live and Suno.
- English prompt output by default for Suno quality and clarity.
- German/English mixed UI where helpful for musical terminology.
- Variable track length with 4-bar grid as the main editing unit.
- Clickable chips, tabs, quick actions, and recommendations before drag and drop.
