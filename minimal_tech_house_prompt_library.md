# 11. Prompt Building Blocks

- Start with kick + minimal texture
- Add percussion every 8 bars
- Introduce bass after intro
- Use filter automation for movement
- Use delay/reverb for transitions
- Keep groove stable but evolving
- Avoid pop structure (verse/chorus)
- Use micro-breakdowns instead of big drops
- End with DJ-friendly outro

---

# 12. Core Philosophy

Minimal techno and deep tech-house rely on:

- repetition + micro variation
- space between sounds
- groove over melody
- tension without explosion
- evolution instead of change
- bass + rhythm interaction
- subtle emotional movement
